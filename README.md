# To-Do List 📝

A simple and user-friendly To-Do List web application built using HTML, JavaScript, and Bootstrap. 
It helps users organize their daily tasks through a clean and responsive interface.

## ✨ Features

- Add and manage daily tasks.
- Simple and clean user interface.
- Responsive design using Bootstrap.
- Easy to use and lightweight.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **JavaScript** – Task functionality and interactivity.
- **Bootstrap 5** – Styling and responsive layout.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/adyvy0008/to-do-list-.git
```

### 2. Open the project

Navigate to the project folder and open `index.html` in your browser.

You can also use the Live Server extension in VS Code to run the application locally.
